# Claude Code

Read `AGENTS.md` and follow it. Skills are `skills/<name>/SKILL.md`. Docs are just-in-time under `docs/`. Do not pre-read the vault.

After a large feature, run `docs/processes/pre-review-qa.md` before reporting done. Independent work defaults to parallel tool calls and concurrent sub-agents (`docs/rules/parallel-operations.md`). Hardcoded strings and mappings use the `## WARNING` variant in `docs/rules/report-hardcoded-strings.md`.
